# Kawiarnia Pod Orzechem – demo nr 3 (firma fikcyjna)

Projekt demonstracyjny do portfolio, zbudowany na szablonie `strona-szablon`. HTML + CSS + minimalny JS, bez zależności, cookies i zewnętrznych skryptów.

- Tryb demo: formularz niczego nie wysyła, `noindex, nofollow`, `robots.txt` z `Disallow: /`, brak JSON-LD i sitemap.
- Style: zmienne `:root` na górze `css/style.css`; układy tego dema w bloku „BLOK: KAWIARNIA”.
- Zdjęcia: surowe pliki wrzuć do `img/raw/` (nazwy jak w `../kawiarnia-zdjecia.py`) i uruchom `python ../kawiarnia-zdjecia.py`.
- Fonty: Fraunces i Nunito Sans (SIL OFL, pliki licencji w `fonts/`).
- Do podmiany przed publikacją: `[MIASTO]`, `[MOJE IMIĘ]`, `[LINK DO PORTFOLIO]`, `[LINK INSTAGRAM]`.
